# Voice

In EDIT mode on personal writing, the author must recognise the result as theirs. In STRICT mode (docs, specs, release notes) there is no personal voice, so rules apply uniformly.

## Detect the voice

Read the whole draft before touching it. Note:

- Vocabulary: words only this person uses, slang, a field's jargon used correctly.
- Cadence: short and blunt, long and winding, spoken fragments, trailing asides.
- Stance: confidence level, humor, bluntness, swearing, how it handles doubt.
- Specifics: names, places, numbers, odd comparisons. Specifics are almost always human; protect them.
- Habits: a repeated word, a favourite construction, a sign-off.
- Polish: a rough draft stays rough. Do not raise the finish.

Text with many of these needs a light hand. Text with none (smooth, generic, symmetric, no named thing) is the target.

## Edit with a light hand

1. Cut only what matches a rule and carries no fact or personality.
2. Prefer deletion to rewording; prefer one word to a rewritten sentence.
3. Do not unify paragraphs. Uneven is human.
4. Keep real doubt ("I'm not sure"), real opinions and real digressions.
5. If a fix would change the meaning or the stance, flag it in What changed instead of applying it.

## When a rule may break

A rule may be broken when all three hold: the pattern is the author's deliberate choice, it carries meaning a replacement would lose, and it is not stacked with other patterns.

- Binary contrast (NS-P-04): fine when the writer answers a view someone really holds.
- Fragment (NS-P-07): fine for one real change of pace, not three in a row.
- Hedge (NS-P-19): fine at the one place the writer is unsure.
- Em dash (NS-P-21): fine in the author's own style, up to two in long text.
- Short punchy ending (NS-P-10): fine when it is a plain fact or the author's habit, not a staged lesson.
- Jargon (NS-P-16): fine in a field where the term is the standard word.
- Quotes and code: never flag text inside a quotation or a code block.

Record a kept pattern under "Kept on purpose" in What changed. In STRICT mode, a break needs a written reason in the notes; Hard rules (NS-P-01, NS-P-25) never break.

## Never

- Add claims, stats, examples, jokes or opinions the author did not write.
- Translate the author's register ("pretty good" to "excellent", or the reverse).
- Replace a named person or place with a category.
