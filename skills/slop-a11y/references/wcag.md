# WCAG 2.2 criteria cited by slop-a11y

One line each, written for this plugin. Level in brackets. Official text: w3.org/TR/WCAG22.

| Criterion | Rule | Meaning |
|---|---|---|
| 1.1.1 Non-text Content [A] | NS-A-09 | Images, icons and charts have a text alternative, or are marked decorative. |
| 1.3.1 Info and Relationships [A] | NS-A-10, 13 | Structure shown visually (headings, lists, tables, field groups) is also in the markup. |
| 1.3.5 Identify Input Purpose [AA] | NS-A-10 | Personal data fields carry the right `autocomplete` value. |
| 1.4.1 Use of Color [A] | NS-A-03 | Colour is never the only way to show meaning. |
| 1.4.3 Contrast (Minimum) [AA] | NS-A-01 | Text has 4.5:1, large text 3:1. |
| 1.4.4 Resize Text [AA] | NS-A-17 | Text can reach 200% with no loss of content. |
| 1.4.10 Reflow [AA] | NS-A-17 | No two-dimensional scrolling at 320 CSS px width. |
| 1.4.11 Non-text Contrast [AA] | NS-A-02 | UI components and graphics have 3:1 against neighbours. |
| 1.4.12 Text Spacing [AA] | NS-A-17 | Content survives larger line, letter and word spacing. |
| 1.4.13 Content on Hover or Focus [AA] | NS-A-04 | Hover or focus popups can be dismissed, hovered and persist. |
| 2.1.1 Keyboard [A] | NS-A-04 | All functions work from the keyboard. |
| 2.1.2 No Keyboard Trap [A] | NS-A-06 | Focus can always leave a component with standard keys. |
| 2.2.1 Timing Adjustable [A] | NS-A-18 | Time limits can be turned off, adjusted or extended. |
| 2.2.2 Pause, Stop, Hide [A] | NS-A-14 | Moving or auto-updating content can be paused. |
| 2.3.1 Three Flashes [A] | NS-A-14 | Nothing flashes more than 3 times a second. |
| 2.3.3 Animation from Interactions [AAA] | NS-A-14 | Motion from interaction can be disabled; used as the basis for reduced motion. |
| 2.4.1 Bypass Blocks [A] | NS-A-13 | A skip link or landmarks let users jump past repeated blocks. |
| 2.4.3 Focus Order [A] | NS-A-04 | Focus order keeps meaning and operability. |
| 2.4.6 Headings and Labels [AA] | NS-A-10, 13 | Headings and labels describe their topic or purpose. |
| 2.4.7 Focus Visible [AA] | NS-A-05 | Keyboard focus is visible. |
| 2.4.11 Focus Not Obscured (Minimum) [AA] | NS-A-05 | A focused item is not fully hidden by sticky content. |
| 2.5.1 Pointer Gestures [A] | NS-M-07 | Multi-point and path gestures have a single-pointer alternative. |
| 2.5.3 Label in Name [A] | NS-A-08 | The accessible name contains the visible label text. |
| 2.5.7 Dragging Movements [AA] | NS-A-18 | Dragging has a single-pointer alternative. |
| 2.5.8 Target Size (Minimum) [AA] | NS-A-16 | Targets are at least 24 by 24 CSS px, or spaced. |
| 3.1.1 Language of Page [A] | NS-A-12 | The page language is set in code. |
| 3.1.2 Language of Parts [AA] | NS-A-12 | Passages in another language are marked. |
| 3.2.2 On Input [A] | NS-A-11 | Changing a field does not cause an unexpected context change. |
| 3.3.1 Error Identification [A] | NS-A-11 | Errors are found and described in text. |
| 3.3.2 Labels or Instructions [A] | NS-A-10 | Fields have labels or instructions. |
| 3.3.3 Error Suggestion [AA] | NS-A-11 | Where known, the fix is suggested. |
| 3.3.7 Redundant Entry [A] | NS-A-18 | Do not ask again for what the user already gave in the same flow. |
| 3.3.8 Accessible Authentication (Minimum) [AA] | NS-A-18 | No memory or puzzle test to sign in; paste and password managers work. |
| 4.1.2 Name, Role, Value [A] | NS-A-08 | Custom controls expose name, role, state and value. |
| 4.1.3 Status Messages [AA] | NS-A-15 | Status changes are announced without moving focus. |
